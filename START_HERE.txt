Getting it running:
-------------------

Step 1: You'll need MongoDB installed and running
The easiest way is with Docker:
  docker run -d -p 27017:27017 --name mongodb mongo:latest

Or if you prefer to install it locally, check out MONGODB_SETUP.md for instructions.

Step 2: Set up your environment variables
First, copy the example file:
  cd refactored_code
  cp env.example .env

Then edit the .env file and add your API keys:
  DEEPGRAM_API_KEY=your_deepgram_key_here
  OPENAI_API_KEY=your_openai_key_here
  AUTH_USERNAME=admin
  AUTH_PASSWORD=your_secure_password
  SECRET_KEY=your_jwt_secret_key
  MONGODB_URL=mongodb://localhost:27017
  MONGODB_DB_NAME=audio-to-text-db

Step 3: Start it up
Make the startup script executable and run it:
  chmod +x start.sh
  ./start.sh

Step 4: Check if it's working
Open your browser and go to: http://localhost:8000/docs

That should be it! The API should be running now.

API Endpoints:
--------------
Here's what you can do with this API:

POST /api/v1/auth/login           - Log in and get an access token
POST /api/v1/transcribe           - Transcribe audio files (and optionally generate SOAP notes)
POST /generate-soap               - Generate SOAP notes from text
POST /api/v1/feedback/submit      - Submit feedback
GET  /api/v1/feedback/stats       - Get feedback statistics
GET  /api/v1/feedback/all         - Get all feedback entries
GET  /health                      - Check if the server is running
GET  /docs                        - View interactive API documentation

What this does:
---------------
The system handles medical audio transcription using Deepgram's Nova-3 model. It can generate SOAP notes using GPT-4, stores feedback in MongoDB, handles authentication with JWT, and supports different audio formats (OPUS, WAV, MP3). It also does some medical terminology corrections automatically.

- If you're using OPUS files, make sure FFmpeg is installed (brew install ffmpeg)
